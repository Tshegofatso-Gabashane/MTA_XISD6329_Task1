MOGALE TENNIS ASSOCIATION WEBSITE — UPDATED VERSION

Files included:
- index.html and the other website pages
- style.css (consistent forest-green and gold theme, responsive layout)
- script.js (safe page-specific form and mobile-menu handling)

HOW TO UPDATE THE WEBSITE ON GITHUB
1. Open your GitHub repository.
2. Open each updated file and replace its contents with the matching file from this folder, OR upload the files while preserving the folder structure.
3. Make sure index.html is in the publishing folder (usually repository root).
4. Commit the changes to the branch configured in Settings > Pages.
5. Check Actions / Settings > Pages for deployment status and open the published URL.

NOTES
- Contact form is a front-end demonstration and does not send email or save submissions to a server.
- Login is a demonstration only; it is not secure authentication. Do not use the demo credentials for real accounts.
- Some tennis photos are loaded from Unsplash and need an internet connection.
